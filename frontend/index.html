Deployment Recommendation
Use LightGBM (tuned) with a decision threshold of 0.460 — tuned from the default 0.500 to boost recall. At this threshold, the model identifies 64.93% of all delayed flights (up from ~56% at default), enabling proactive passenger notification at check-in. The ensemble (LGB+XGB+CatBoost) achieved slightly higher ROC-AUC (0.6763) but a single LightGBM model was selected for simpler deployment.

How it works
This form sends a POST request to /api/predict on your FastAPI backend. Your preprocessor.joblib transforms the raw inputs, scaler.pkl normalises them, and best_tuned_model.pkl (LightGBM tuned) outputs the delay probability. The classification threshold is set to 0.460 — tuned from the default 0.500 to maximise recall on the delayed class (F1 0.4446, Recall 64.93%).
